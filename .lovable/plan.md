# مركز الأدوات المفتوحة — ربط كل أداة بصفحتها في المنصة

الهدف: سجل موحّد لكل أدوات إدارة السيرفرات والمواقع (Cockpit, Portainer, Netdata, Restic, pgAdmin, Ansible… ~45 أداة)، لكل أداة معرّف خاص وصفحة شاملة، مع علاقات تربطها بصفحات المنصة والسيرفرات والمواقع، وأزرار تشغيل/تثبيت عبر وكيل TVCC الموقّع.

## 1. سجل الأدوات (جداول جديدة — إضافية بالكامل)

- `platform_tools` — كل أداة: معرّف بشري `TL-####`، الاسم، الفئة (9 فئات كما في قائمتك)، الترخيص، الدور، المنفذ الافتراضي، أمر التثبيت، رابط الخدمة، الأيقونة، الحالة.
- `platform_tool_pages` — علاقة أداة ↔ صفحة منصة (`platform_pages`)، مع نوع الربط: أساسية / ثانوية.
- `platform_tool_installs` — أداة ↔ سيرفر (أو موقع): الحالة (غير مثبتة / قيد التثبيت / تعمل / متوقفة)، الإصدار، المنفذ، آخر فحص، رابط الوصول.
- `platform_tool_links` — علاقات بين الأدوات نفسها (Prometheus ↔ Grafana، Loki ↔ Grafana، Cockpit ↔ Podman).

كل جدول: صلاحيات + RLS (قراءة للمصادَقين، كتابة للمدير/المالك) + `updated_at`. لا حذف ولا تعديل لأي جدول قائم.

## 3. الصفحات

- **`/tools` — مركز الأدوات**: جدول موحّد (معرّف، أداة، فئة، ترخيص، الصفحات المرتبطة، عدد السيرفرات المثبَّتة، الحالة) مع بحث وتصفية حسب الفئة وتصدير CSV.
- **`/tools/$toolId` — صفحة شاملة لكل أداة**: التعريف والدور والترخيص، أوامر التثبيت/التشغيل/الإيقاف، المنفذ ورابط الفتح، جدول السيرفرات المثبَّتة عليها، الصفحات المرتبطة، الأدوات المرتبطة، سجل العمليات الأخير، وأزرار: تثبيت · تشغيل · إيقاف · فحص الحالة · فتح الواجهة.
- **شريط «أدوات هذه الصفحة»**: مكوّن صغير يُضاف أعلى/أسفل كل صفحة من الصفحات المذكورة (السيرفرات، مركز التحميل، مركز الربط، خريطة العلاقات، شبكة السيرفرات، النسخ الاحتياطي، مذكّرة العمليات، مركز السجلات، التحويل التلقائي، النشر من Git، توحيد النشر، الأتمتة والمراقبة، النطاقات، ‎.HN‎، الجسر والتخزين، استضافتي، SSL، شهادات HN.RLS، الإشعارات، إدارة البيئة، سجل النشاط، التقارير، مركز المراقبة، الحاويات، قواعد البيانات، الوكيل، الخزينة، الاستعادة، فحص النظام…) يعرض بطاقات الأدوات المرتبطة بتلك الصفحة مع حالتها وزر فتح صفحتها.

## 4. التنفيذ على السيرفرات

- كل تثبيت/تشغيل/إيقاف يمر عبر طابور أوامر الوكيل الموقّع الحالي (`server_commands`) بأمر جديد `tool_action` (install / start / stop / status / uninstall) مع تسجيل النتيجة في `platform_tool_installs` و`operation_log`.
- تحديث سكربت الوكيل ليتعامل مع `tool_action` عبر `apt/docker` حسب تعريف الأداة، بمهلة زمنية وحد لحجم المخرجات.
- التثبيت والإزالة للمالك/المدير فقط؛ المشاهد يرى الحالة فقط.

## 5. تفاصيل تقنية

- يحمل كل سجل أداة الحقول التفصيلية من جدولك: الفئة، الترخيص/النموذج، التقنيات/اللغة، المنفذ/الواجهة، الحزم والخدمات والمسارات المهمة، أقسام الواجهة الأساسية، وملاحظات تقنية مهمة — وتظهر كلها في صفحة الأداة وتُستخدم في الفلترة والبحث.

- الواجهة: TanStack Router — `src/routes/_authenticated/tools.index.tsx` و`tools.$toolId.tsx`، مكوّن `src/components/tools/PageTools.tsx`.
- الخادم: `src/lib/tools.functions.ts` (قائمة، تفاصيل، ربط صفحة، تثبيت، فحص) بـ `requireSupabaseAuth` وتحقق الدور.
- تسجيل الصفحتين في `platform_pages` بحد أدنى للدور: مشاهد للعرض، مدير للتنفيذ.
- لا حذف ولا تغيير لأي بيانات أو جداول قائمة — كل شيء إضافي.

## ملاحظة
الأدوات تُعرض وتُدار من المنصة، لكن التثبيت الفعلي يحدث فقط على السيرفرات التي عليها وكيل TVCC محدَّث؛ غير ذلك تبقى الحالة «غير مثبتة» مع أمر جاهز للنسخ.
