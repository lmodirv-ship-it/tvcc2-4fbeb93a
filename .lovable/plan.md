# صفحة الوكيل (Agent Control) — جدولان: السيرفرات والمهام

إعادة بناء صفحة الوكيل لتصبح قسمين واضحين بجدولين، بدل الواجهة الحالية.

## القسم الأول: جدول حالة السيرفرات (12 خانة)

صف لكل سيرفر يبدأ بمعرّف السيرفر، مع بحث وفرز وتحديث تلقائي كل 30 ثانية:

1. المعرّف (ID مختصر + نسخ)
2. اسم السيرفر
3. العنوان/المضيف (hostname أو IP)
4. الحالة (متصل / متوقف / تحذير)
5. إصدار الوكيل
6. آخر اتصال (منذ كم دقيقة)
7. نظام التشغيل
8. المعالج %
9. الذاكرة %
10. القرص %
11. عدد الأوامر الجارية / المعلّقة
12. إجراءات: تشخيص، تحديث الوكيل، إعدادات، فتح صفحة السيرفر

## القسم الثاني: جدول مهام الوكيل

كل الأوامر المتاحة للوكيل في جدول واحد يبدأ بمعرّف المهمة:

- معرّف المهمة (رمز الأمر مثل `disk_usage`)
- الاسم بالعربية
- التصنيف (مراقبة / خدمات / مواقع / قواعد بيانات / شبكة / نسخ احتياطي / نظام)
- مستوى الخطورة (آمن / يحتاج تأكيد)
- الحالة: مفعّلة أو معطّلة على السيرفر المختار
- آخر تنفيذ ونتيجته
- زر **تفعيل/تعطيل** (مفتاح يحدّث صلاحية الأمر للسيرفر المختار)
- زر **تشغيل الآن** (يضع الأمر في الطابور فوراً)

أعلى الجدول: اختيار السيرفر، بحث، فلترة حسب التصنيف/الحالة، وأزرار «تفعيل الكل» و«تعطيل الكل».

### إضافة مهمة

زر **إضافة مهمة** يفتح نافذة لإنشاء مهمة مركّبة: العنوان، السيرفر، ونوع الأمر مع وسائطه (خطوة واحدة أو عدة خطوات بالترتيب)، وخيار محاكاة (Dry Run). بعد الحفظ تُدرج المهمة في الطابور وتظهر في جدول «المهام الأخيرة» مع الحالة والنتيجة.

## القسم الثالث (يبقى كما هو)

إعدادات الوكيل لكل سيرفر، ملفات Nginx، واللقطات — تنتقل إلى تبويبات أسفل الجدولين حتى لا تُفقد.

## تفاصيل تقنية

- توسيع `getAgentsData` في `src/lib/federated.functions.ts` لإرجاع: `agent_instances`، آخر `server_health_snapshots` لكل سيرفر، `agent_capabilities`، وآخر تنفيذ لكل أمر (من `server_commands`).
- مصدر قائمة المهام: `COMMAND_WHITELIST` + `COMMAND_LABELS` في `src/lib/server-commands.ts`، مع خريطة تصنيفات جديدة في نفس الملف.
- التفعيل/التعطيل عبر `setAgentCapability` الموجودة، والتشغيل عبر `dispatchAgentCommand`، وإضافة مهمة عبر `createAgentJob` (كلها في `src/lib/agent-roles.functions.ts`) — لا حاجة لجداول جديدة.
- إعادة كتابة `src/routes/_authenticated/federated.agents.tsx` بجدولين + تبويبات، مع `useQuery` وتحديث دوري، وحفظ السيرفر المختار في الحالة المحلية.
- لا تغيير في قاعدة البيانات ولا في سكربت الوكيل.
