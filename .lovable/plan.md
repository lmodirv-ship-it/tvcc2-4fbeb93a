# إضافة كل مواقع لوفابل إلى المنصة + معرّف ID لكل موقع + زر Connect

## الهدف
1. استيراد كل مواقعك دفعة واحدة (بدون فحص) مع منح كل موقع رقم تعريف ثابت `IDXXXXX` لتسهيل الإدارة.
2. زر **Connect** أسفل زر المواقع في لوحة التحكم يفتح صفحة الربط.
3. إدراج موقع **TVCC** ضمن لائحة صفحة الربط.

## 1. قاعدة البيانات
- إضافة عمود `site_code` (نص، فريد) إلى جدول `websites`.
- تسلسل `website_code_seq` + دالة/trigger تولّد الرمز تلقائياً بصيغة `ID00001` لكل موقع جديد.
- تعبئة كل المواقع الحالية (188) بأرقام تعريف مرتبة حسب تاريخ الإنشاء.
- فهرس فريد على `site_code` للبحث السريع.

## 2. صفحة الاستيراد الجماعي
صفحة جديدة `/import-sites`:
- مربع نص كبير: تلصق فيه أي عدد من النطاقات (سطر لكل موقع، يقبل `name | domain` أو نطاق فقط).
- يستخرج اسم الموقع تلقائياً من النطاق إن لم يُذكر.
- **تجاهل المكرر**: أي نطاق موجود مسبقاً لا يُلمس، والجديد فقط يُضاف.
- بدون فحص HTTP/SSL (استيراد فقط، الحالة `pending`).
- تقرير بعد التنفيذ: عدد المضاف، عدد المتجاهل، مع قائمة الرموز الجديدة.

## 3. عرض المعرّف
- عمود/شارة `IDXXXXX` في صفحة `/websites` مع بحث بالرمز.
- زر نسخ الرمز.

## 4. زر Connect في لوحة التحكم
- تحت زر «المواقع» في `/dashboard` يظهر زر **Connect** بارز يوجّه إلى `/connect`.
- نفس الزر في القائمة الجانبية إن لم يكن ظاهراً.

## 5. صفحة الربط (/connect)
- إضافة بطاقة/عنصر ثابت لخدمة **TVCC** (النطاق الرسمي `tvcc.hnpay.live`) ضمن لائحة الخدمات القابلة للربط، مع حالة الاتصال الحية عبر `/api/public/publish/status`.
- إبقاء بقية الخدمات (قواعد بيانات، تخزين، نماذج ذكاء، API…) كما هي.

## التفاصيل التقنية
- Migration: `ALTER TABLE public.websites ADD COLUMN site_code text UNIQUE` + `CREATE SEQUENCE` + trigger `BEFORE INSERT` يملأ الرمز، ثم `UPDATE` لتعبئة الصفوف الحالية.
- دالة خادم `bulkImportWebsites` في `src/lib/supabase-import.functions.ts` (موجود) — إدراج بـ `upsert` على `domain` مع `ignoreDuplicates`.
- الصفحة الجديدة: `src/routes/_authenticated/import-sites.tsx` + رابط في `AppSidebar.tsx` وترجمات ar/fr/en.
- تعديل `src/routes/_authenticated/dashboard.tsx` لزر Connect، و`connect.tsx` لبطاقة TVCC.
