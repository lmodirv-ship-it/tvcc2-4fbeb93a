# مركز التحميل — رفع مجلد من الحاسوب إلى السيرفر وبناؤه وتشغيله

إضافة تبويب جديد «نقل وبناء» في صفحة `/downloads` يسمح باختيار مجلد/ملفات من الحاسوب، وتحديد السيرفر (أو IP + كلمة مرور)، ثم رفعها إلى `/home/ismail/hn/<اسم-الملف>` على السيرفر، وتشغيل البناء، وفتح منفذ، وتشغيل الموقع كخدمة دائمة (daemon).

لا يتم حذف أو تغيير أي شيء قائم — إضافات فقط.

## طريقتان للنقل (الاثنتان في نفس الصفحة)

1) **عبر الوكيل (موصى بها، تلقائية بالكامل)**
   - المتصفح يضغط الملفات المختارة إلى أرشيف واحد ويرفعه إلى مخزن المنصة.
   - الوكيل المثبّت على السيرفر يسحب الأرشيف، ينشئ `/home/ismail/hn/<الاسم>`، يفكّه، يبني، يفتح المنفذ، ويشغّل الخدمة.
   - لا حاجة لكلمة مرور SSH إطلاقاً.

2) **عبر PowerShell (للسيرفرات بلا وكيل)**
   - تُدخل IP + المستخدم + كلمة المرور + المنفذ المطلوب، فتولّد المنصة سكربت PowerShell جاهزاً للصق في نافذة أوامر Windows.
   - السكربت يستخدم OpenSSH المدمج في Windows (`scp`/`ssh`)، ومع كلمة المرور يستعمل `plink/pscp` أو `sshpass` تلقائياً حسب المتوفر.
   - كلمة المرور لا تُخزَّن افتراضياً؛ خيار اختياري «حفظ في الخزنة» يخزّنها مشفّرة (AES-256-GCM) في الخزنة الحالية.

## خطوات التشغيل على السيرفر (نفس المنطق في الطريقتين)

```text
mkdir -p /home/ismail/hn/<name>  →  فكّ الأرشيف
كشف نوع المشروع: package.json (bun/pnpm/npm) · requirements.txt · index.html ثابت
تثبيت الاعتماديات → أمر البناء → كشف مجلد الإخراج (dist/build/out/public)
اختيار منفذ حر (المنفذ المطلوب أو أول منفذ حر بعده)
كتابة وحدة systemd: tvcc-hn-<name>.service  →  daemon-reload · enable · start
ufw allow <port>/tcp  →  فحص http://127.0.0.1:<port>
```

## معالجة أخطاء البناء (كل الاحتمالات)

- Node/Bun غير مثبت → تثبيت تلقائي، وإلا رسالة واضحة بالأمر المطلوب.
- فشل `install` → إعادة المحاولة بمدير حزم بديل ثم `--legacy-peer-deps`.
- لا يوجد أمر build → تشغيل مباشر (`start`) أو تقديم ثابت عبر خادم بسيط.
- المنفذ مشغول → اختيار المنفذ التالي الحر وإعلامك به.
- نفاد الذاكرة أثناء البناء → إعادة المحاولة مع `NODE_OPTIONS=--max-old-space-size`.
- فشل الخدمة بعد التشغيل → عرض آخر 200 سطر من `journalctl` داخل الواجهة.
- كل محاولة ونتيجتها تُسجَّل ويمكن «إعادة المحاولة» أو «محاكاة Dry Run» قبل التنفيذ.

## الواجهة (`/downloads` › تبويب «نقل وبناء»)

- اختيار مجلد من الحاسوب (رفع مجلد كامل) + عرض عدد الملفات والحجم.
- اختيار سيرفر من القائمة، أو وضع يدوي: IP · المستخدم · كلمة المرور · المنفذ.
- خيارات: أمر التثبيت/البناء، مجلد الإخراج، اسم الخدمة، فتح المنفذ في الجدار الناري.
- زران: «محاكاة» و«نقل وبناء وتشغيل»، مع سجل مباشر للخطوات وحالة كل خطوة.
- بطاقة لكل عملية سابقة: الحالة، المنفذ، رابط المعاينة `http://IP:PORT`، وزر السجل.
