# مكتبة نماذج الجداول + ترقية مركز قواعد البيانات

## الهدف
إضافة مكتبة نماذج جاهزة (Blueprints) للجداول التي تحتاجها أغلب المواقع، بحيث يستطيع المالك اختيار نموذج وتطبيقه على أي قاعدة بيانات بضغطة واحدة — مع معاينة الأوامر قبل التنفيذ وتسجيل كل شيء. وفي نفس الوقت تفعيل بقية أقسام صفحة قواعد البيانات لتؤدي دوراً حقيقياً بدل العرض فقط.

## 1) مكتبة النماذج (تبويب جديد: «النماذج»)
كل نموذج = مجموعة جداول مترابطة + مفاتيح + فهارس + سياسات حماية + بيانات تجريبية اختيارية.

النماذج المقترحة:
- أساس الموقع: profiles، user_roles، settings، media، audit_log
- مدوّنة/محتوى: posts، categories، tags، post_tags، comments
- متجر: products، variants، categories، customers، orders، order_items، payments، coupons، inventory
- حجوزات: services، staff، availability، bookings، booking_status
- عملاء/CRM: contacts، companies، deals، activities، notes
- دعم فني: tickets، ticket_messages، priorities، assignments
- تعليم: courses، lessons، enrollments، progress، quizzes
- نشرة بريدية ونماذج اتصال: subscribers، campaigns، contact_messages
- إحصائيات: page_views، events، daily_stats

لكل نموذج في الواجهة:
- بطاقة فيها الاسم، الوصف، عدد الجداول، والعلاقات.
- زر «معاينة» يعرض أوامر الإنشاء كاملة قبل أي تنفيذ.
- خيارات: تفعيل حماية الصفوف (افتراضياً نعم)، بادئة أسماء اختيارية، تخطي الجداول الموجودة، إدراج بيانات تجريبية.
- زر «تطبيق عبر الوكيل» مع تأكيد صريح، ثم عرض النتيجة (نجاح/فشل لكل جدول).
- «فحص التوافق»: مقارنة النموذج بالجداول الموجودة فعلاً وإظهار الناقص والمتعارض قبل التطبيق.
- إمكانية حفظ نموذج خاص من قاعدة قائمة («استخرج نموذجاً من هذه القاعدة») لإعادة استخدامه في مواقع أخرى.

## 2) ترقية بقية أقسام الصفحة
- نظرة عامة: أرقام حقيقية (عدد الجداول، الحجم، آخر نسخة، حالة الوكيل، آخر خطأ).
- الجداول: موجود بالفعل — يُضاف إليه زر «أنشئ من نموذج» عند فراغ القاعدة.
- SQL: حفظ الاستعلامات المفضلة وسجل آخر الاستعلامات وإعادة تشغيلها.
- النسخ الاحتياطي: جدولة، قائمة النسخ، واستعادة بتأكيد نصي.
- المراقبة: أبطأ الاستعلامات، الاتصالات، حجم الجداول الأكبر.
- الصحة: فحص تلقائي (جداول بلا حماية، بلا مفتاح أساسي، فهارس ناقصة، أعمدة تواريخ مفقودة) مع اقتراح إصلاح قابل للتطبيق.
- الإعدادات: ربط القاعدة بسيرفر عليه وكيل مباشرة من الصفحة (يحل رسالة «غير مرتبطة بوكيل»).

## التفاصيل التقنية
- تعريف النماذج في `src/lib/db-templates.ts` كبيانات منظمة (جداول/أعمدة/علاقات/فهارس/سياسات)، وبناء SQL على الخادم فقط من معرّفات محقّقة — لا نص حر من المتصفح.
- دوال خادم جديدة في `src/lib/dbstudio.functions.ts`: `previewTemplate`، `applyTemplate`، `inspectTemplateDiff`، `extractTemplate` — كلها خلف `requireSupabaseAuth` + تحقق admin/owner، وتُنفَّذ عبر أوامر الوكيل الحالية (`pg_ddl` / `pg_meta` / `pg_write`) مع تسجيل في سجل التدقيق والسجل الأمني.
- كل تطبيق يستخدم `create table if not exists` وتفعيل RLS وسياسات افتراضية (مالك الصف عبر `auth.uid()` أو قراءة عامة للمحتوى المنشور حسب النموذج) مع فهارس على المفاتيح الأجنبية وأعمدة التواريخ + مشغّل `updated_at`.
- واجهة جديدة: `src/components/dbstudio/TemplateLibrary.tsx` مربوطة بقسم جديد في `src/routes/_authenticated/federated.db.tsx`، بنفس نمط عرض نتائج الوكيل المستخدم في محرر الجداول.
- لا تغيير على مخطط قاعدة بيانات المنصة نفسها؛ النماذج تُطبَّق على قواعد المواقع عبر الوكيل.

## المراحل
1. ملف النماذج + دوال المعاينة/الفرق.
2. تبويب «النماذج» مع المعاينة والتطبيق وعرض النتائج.
3. فحص التوافق واستخراج نموذج من قاعدة قائمة.
4. ترقية النظرة العامة والصحة والنسخ والمراقبة والإعدادات.
