# زر Cockpit داخل إدارة السيرفرات

إضافة زر **Cockpit** أسفل كل سيرفر في صفحة إدارة السيرفرات، يفتح صفحة داخل المنصة بنفس أقسام كوكبيت الأحد عشر، تعمل عبر وكيل TVCC المثبت على السيرفر — مع زر جانبي لفتح كوكبيت الأصلي `https://<ip>:9090` في تبويب جديد.

## الأزرار الجديدة

- في بطاقة/صف كل سيرفر: زر **Cockpit** تحت زر «لوحة السيرفر».
- داخل صفحة السيرفر: نفس الزر في شريط الأدوات.
- زر «فتح كوكبيت الأصلي» يستعمل عنوان السيرفر المسجّل (العام أو الخاص) والمنفذ 9090.

## الصفحة الجديدة `/servers/$serverId/cockpit`

قائمة جانبية عربية بنفس ترتيب كوكبيت، وكل قسم يعرض بيانات حقيقية:

| القسم | المصدر |
|---|---|
| النظام | سجل السيرفر: الاسم، النظام، المعالج، الذاكرة، القرص، معرّف الجهاز، مدة التشغيل |
| نظرة عامة | مخططات حية للمعالج/الذاكرة/القرص/الشبكة من `server_metrics` |
| السجلات | أمر `service_logs` + سجلات الوكيل، مع تصفية حسب الخطأ/التحذير والخدمة |
| التخزين | `server_disks` + أمر `disk_usage` |
| الشبكة | `server_net_interfaces` + `server_ports` + قواعد الجدار الناري (`firewall_list`) مع سماح/منع |
| الحسابات | أمر جديد `users_list` لعرض مستخدمي النظام (قراءة فقط في المرحلة الأولى) |
| الخدمات | `server_services` مع تشغيل/إيقاف/إعادة تشغيل/تمكين عبر `service_status` و`service_restart` وأمر جديد `service_action` |
| الأدوات | مدير الملفات القائم (`fs_*`) + قائمة العمليات (`proc_list`) + الحاويات (`docker_ps`) |
| التطبيقات | أمر جديد `pkg_list` لعرض الحزم المثبتة |
| تحديثات البرامج | أمران جديدان `pkg_updates` (فحص) و`pkg_upgrade` (تثبيت، مع تأكيد) |
| الطرفية المتقدمة | جلسة تفاعلية غير مقيّدة للمالك داخل المتصفح، وتحتها زر «الأوامر» يفتح دليلاً قابلاً للبحث يشرح الأمر ووظيفته ومثاله، منظماً إلى: الملفات، مراقبة النظام، المستخدمون والصلاحيات، الحزم، الشبكة، العمليات، خدمات Systemd، التخزين، ومعالجة النصوص |

مؤشرات التنبيه الحمراء بجانب «الخدمات» و«التحديثات» عند وجود خدمة فاشلة أو تحديثات معلّقة، كما في كوكبيت.

## الطرفية والأمان

- الطرفية تنفّذ أوامر Cockpit المعتمدة: تثبيت/إزالة Cockpit ووحداته، تشغيل/إيقاف/تمكين وفحص `cockpit` و`cockpit.socket`، فتح وفحص المنفذ 9090، عرض السجلات المباشرة، فحص الوحدات وتحديثها؛ أمراً واحداً في كل مرة وترجع المخرجات؛ ليست جلسة SSH تفاعلية.
- متاحة للمالك والمدير فقط، وكل أمر يُسجَّل في سجل العمليات مع منفّذه ووقته.
- قائمة منع للأوامر المدمّرة (حذف الجذر، إيقاف الوكيل، تغيير كلمة مرور الجذر) مع رسالة واضحة.
- كل العمليات تبدأ باتصال SSH مباشر آمن مثل `root@192.168.100.66` مع إدخال كلمة السر مرة واحدة وحفظها مشفّرة، ثم يُضاف السيرفر بمعرّف خاص ويُثبَّت عليه Cockpit؛ بعد ذلك تمر المهام عبر الوكيل الموقّع. تُنشأ علاقات معرّفة بين السيرفر وصفحات Cockpit وباقي صفحات المنصة وقواعد البيانات والأدوار والمهام، وتتكرر العملية نفسها لكل سيرفر.

## تفاصيل تقنية

- مسار جديد `src/routes/_authenticated/servers.$serverId.cockpit.tsx` + مكوّنات أقسام تحت `src/components/servers/cockpit/`.
- دوال `createServerFn` مع `requireSupabaseAuth` في `src/lib/cockpit.functions.ts` (قراءة الحالة + إرسال أوامر + استطلاع النتائج كل ثانيتين).
- توسيع `COMMAND_WHITELIST` في `src/lib/server-commands.ts` بـ: `users_list`, `service_action`, `pkg_list`, `pkg_updates`, `pkg_upgrade`, `shell_exec` — مع تسمياتها العربية وإدراج `pkg_upgrade` و`shell_exec` ضمن الأوامر الخطرة.
- ترقية سكربت الوكيل في `src/lib/agent-script.ts` لتنفيذ الأوامر الستة الجديدة (مهلة زمنية وحد لحجم المخرجات).
- تسجيل الصفحة في سجل الصفحات (`platform_pages`) بحد أدنى للدور: مدير.
- لا حذف ولا تعديل لأي جدول أو بيانات قائمة — كل شيء إضافي.
- زر «تثبيت كوكبيت على السيرفر» يرسل إلى الوكيل: `apt install cockpit -y` ثم `systemctl start cockpit`، مع عرض المخرجات وتفعيل رابط `https://<ip>:9090` بعد النجاح (مطبَّق أولاً على hn-groupe).

## ملاحظة

الأقسام التي تعتمد على تنفيذ فعلي (الخدمات، التحديثات، الطرفية، الحسابات) تعمل فقط على السيرفرات التي عليها وكيل TVCC محدَّث؛ السيرفرات بلا وكيل تعرض البيانات المخزّنة مع تنبيه واضح.
