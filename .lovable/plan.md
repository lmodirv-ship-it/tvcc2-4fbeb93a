# تطوير صفحة الإعدادات لإدارة المنصة فعلياً

## الوضع الحالي

صفحة الإعدادات `/settings` تعرض حقولاً (اسم المنصة، اللغة، الوضع الداكن، البريد، الهاتف، الإشعارات) لكنها **غير محفوظة**: زر «حفظ» يغلق وضع التحرير فقط ولا يكتب أي شيء في قاعدة البيانات. الجزء الوحيد الحقيقي هو تغيير كلمة السر.

في المقابل توجد جداول جاهزة غير مستعملة في هذه الصفحة:
- `brand_settings` — اسم المنصة، الشعار، الألوان، الخط (سجل واحد عام)
- `user_preferences` — الثيم واللغة وحالة الشريط الجانبي لكل مستخدم
- `notification_preferences` و`notification_channels` — تفضيلات وقنوات الإشعارات
- `user_roles` — الأدوار (مالك/مدير/محرر/مشاهد)

## الهدف

تحويل الإعدادات إلى مركز إدارة حقيقي للمنصة: كل حقل يُقرأ ويُحفظ في قاعدة البيانات، ومربوط بالدور المسموح له بتعديله.

## الشكل الجديد

صفحة بتبويبات:

| التبويب | المحتوى | من يعدّل |
|---|---|---|
| المنصة | اسم المنصة، الشعار، الأيقونة، الوصف، اللغة الافتراضية | مدير / مالك |
| الاتصال | بريد الدعم، الهاتف، واتساب، عنوان، روابط التواصل | مدير / مالك |
| حسابي | اللغة، الثيم، الشريط الجانبي، كلمة السر | كل مستخدم |
| الإشعارات | تفعيل حسب نوع الحدث + قنوات (بريد/تيليغرام/Webhook) | مدير / مالك |
| الأدوار والصلاحيات | جدول الأعضاء وأدوارهم مع مصفوفة الصلاحيات للقراءة، وتعديل الدور | مالك / مدير |
| الشبكة والربط | سجلات DNS الموحدة، النطاق الرسمي، وضع الصيانة | مالك |
| قواعد البيانات | جدول قواعد البيانات المسجّلة (`databases` و`site_databases`): الاسم، النوع، المضيف/المنفذ، السيرفر المرتبط، الحالة، آخر مزامنة — مع إضافة/تعديل/حذف، اختبار الاتصال، وتشغيل المزامنة والنسخ الاحتياطي | مالك / مدير |

| الصفحات والوحدات | سجل بكل صفحات المنصة (نحو 68 صفحة): تفعيل/تعطيل، إظهار في الشريط الجانبي، الحد الأدنى للدور المسموح بالدخول، الترتيب والاسم المعروض | مالك |

كل تبويب يعرض حالة الحفظ، ويُخفي أزرار التعديل لمن لا يملك الصلاحية (عرض فقط).

## التحكم في كل صفحة من الإعدادات

تبويب «الصفحات والوحدات» هو مركز التحكم في المنصة كاملة:
- جدول يضم كل صفحات لوحة التحكم والصفحات العامة مع بحث وتجميع حسب القسم.
- لكل صفحة: مفتاح تفعيل، إظهار/إخفاء من القائمة الجانبية، الدور الأدنى للدخول، الاسم المعروض بالعربية/الفرنسية/الإنجليزية، والترتيب.
- إجراءات جماعية: تفعيل الكل، تعطيل الكل، تطبيق دور على مجموعة صفحات.
- الشريط الجانبي والتوجيه يقرآن هذا السجل: الصفحة المعطّلة تختفي من القائمة، ومحاولة فتحها مباشرة تُظهر رسالة «غير متاحة»، والصفحة المقيّدة بدور أعلى تُرفض.

## قاعدة البيانات

جدولان جديدان:

1. `public.platform_settings` (سجل واحد عام) يضم: بريد الدعم، الهاتف، واتساب، العنوان، روابط التواصل، اللغة الافتراضية، النطاق الرسمي، وضع الصيانة، قيم سجلات DNS، وملاحظات.
2. `public.platform_pages` — سجل صفحات المنصة: المسار، المفتاح، القسم، الأسماء بثلاث لغات، مفعّلة، ظاهرة في القائمة، الدور الأدنى، الترتيب. يُملأ ببيانات كل الصفحات الحالية ضمن نفس الترحيل.

- قراءة: كل مستخدم مسجّل الدخول
- كتابة: `admin` أو `system_owner` فقط عبر `has_role`
- مع `GRANT` للأدوار المناسبة، وتفعيل RLS، ومُشغّل تحديث `updated_at`

باقي التبويبات تستخدم الجداول الموجودة كما هي (لا حذف ولا تغيير هيكلي):
- المنصة → `brand_settings`
- حسابي → `user_preferences`
- الإشعارات → `notification_preferences` + `notification_channels`
- الأدوار → `user_roles` + `profiles`
- قواعد البيانات → `databases` + `site_databases` + `backup_schedules` (تُدار من الإعدادات بدل صفحة منفصلة)

## التفاصيل التقنية

- `src/lib/platform-settings.functions.ts`: دوال خادم بـ `requireSupabaseAuth` للقراءة والتحديث، مع تحقق من الدور داخل المعالج قبل أي كتابة (RLS طبقة ثانية).
- إعادة كتابة `src/routes/_authenticated/settings.tsx` كتبويبات (`Tabs` من shadcn) مع `useQuery`/`useMutation` من TanStack Query و`toast` للتأكيد.
- استخدام `RoleGate` و`usePermissions` الموجودَين لإخفاء/تعطيل التحرير: `settings.manage` للمنصة والاتصال والشبكة، `users.manage` لتبويب الأدوار.
- تبويب «حسابي» يكتب في `user_preferences` ويطبّق الثيم واللغة فوراً عبر `DesignProvider` و`i18n` القائمَين.
- الحفاظ على بطاقة كلمة السر وبطاقة DNS الحاليتين داخل التبويبات المناسبة (إضافة لا حذف).
- `settings.notifications.tsx` الحالية تبقى كما هي، ويُضاف رابط إليها من تبويب الإشعارات.
- تبويب قواعد البيانات يعيد استخدام دوال الخادم الموجودة للنسخ الاحتياطي والمزامنة (`backup-hub.functions.ts` و`connect.functions.ts`) بدل تكرار المنطق، مع إخفاء بيانات الاعتماد وعرض حالة الاتصال فقط.
- سجل الصفحات: `src/lib/platform-pages.functions.ts` للقراءة والتحديث الجماعي، و`usePlatformPages` يستهلكه `AppSidebar` لعرض القائمة، مع مكوّن حارس في `_authenticated` يمنع الدخول إلى صفحة معطّلة أو أعلى من دور المستخدم. المالك الدائم لا يمكن حجبه عن أي صفحة.

## التحقق

- تسجيل الدخول كمالك: تعديل وحفظ كل تبويب ثم تحديث الصفحة والتأكد من بقاء القيم.
- حساب `viewer`: الحقول للعرض فقط دون أزرار حفظ، ومحاولة الكتابة مرفوضة من القاعدة.
- تعطيل صفحة من الإعدادات والتأكد من اختفائها من القائمة ورفض فتحها مباشرة، ثم إعادة تفعيلها.
- فحص البناء والأنواع بدون أخطاء.
