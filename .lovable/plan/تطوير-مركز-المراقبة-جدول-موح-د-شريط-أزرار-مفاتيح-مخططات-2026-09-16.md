# تطوير مركز المراقبة: جدول موحّد + شريط أزرار + مفاتيح + مخططات

الهدف: جعل `/monitoring` لوحة تشغيل واحدة: جدول تفصيلي موحّد لكل موقع مع سيرفره، شريط أزرار أفقي أعلى الصفحة يشغّل كل الخدمات، تبويب مفاتيح وأمان، ومخططات تفاعلية. قاعدة ثابتة: إضافة فقط — لا حذف ولا تعديل لأي جدول أو صف موجود.

## 1. الجدول الموحّد (بدل الجدولين الحاليين)

يُدمج جدول «برامج المواقع» وجدول المواقع الأسفل في جدول واحد مفتاحه `website_id` + `server_id`، يعرض لكل صف:

- كود الموقع (S######) والاسم والنطاق.
- السيرفر المرتبط (اسمه + حالته + آخر نبضة له).
- حالة برنامج الموقع: نقطة خضراء/صفراء/رمادية + عدد النبضات + آخر نبضة + النسخة.
- حالة الموقع (HTTP، زمن الاستجابة، SSL، آخر فحص) من فحوص الصحة.
- المجموعة التي ينتمي إليها والخدمة التي يقدّمها وعدد المستفيدين.
- المهام الدائمة المرتبطة بالموقع (عدد + آخر حالة).
- حالة المفتاح: موجود/مفقود + زر تدوير.
- أزرار الصف: PHP · Node · الشارة · فحص الآن · تشغيل محرّك.

مع بحث، فلاتر (سيرفر / مجموعة / متصل / بدون برنامج)، وترقيم صفحات بدل قصّ أول 60 صفاً.

## 2. شريط الأزرار الأفقي أعلى الصفحة

صف أزرار واحد مضغوط ينفّذ الخدمات فعلياً:

1. تشغيل نبضة المزامنة — تنزيل `tvcc-heartbeat.js` الجاهز بإعدادات المصدر المحلي + زر «تحقّق الآن» يعرض حالة المصدر (online) وأعداد الصفوف من تبويب المزامنة.
2. برنامج السيرفر الموحّد — اختيار سيرفر وتنزيل المثبّت.
3. برنامج الموقع — توليد جماعي لكل المواقع المحدّدة.
4. تسجيل كل المواقع تلقائياً.
5. إنشاء مفتاح مشترك للمجموعة (مفتاح واحد يُستخدم من كل موقع وسيرفر).
6. مزامنة المفاتيح — دفع المفتاح الجديد لكل السجلات مع إبقاء القديم صالحاً لفترة سماح.
7. فحص شامل الآن.
8. إصلاح تلقائي + تقرير.
9. تشغيل كل المحرّكات الدائمة المستحقة.
10. تحديث/تصدير CSV.

## 3. تبويبات مركز المراقبة

تُنظَّم الصفحة في تبويبات: **نظرة عامة · المواقع والسيرفرات · المحرّكات · المزامنة · المفاتيح والأمان · المخططات**.

تبويب «المفاتيح والأمان»:
- جدول بمفتاح كل موقع (بصمة المفتاح فقط، لا يُعرض المفتاح الكامل إلا مرة واحدة عند التوليد).
- توليد/تدوير مفتاح لموقع واحد أو للكل، وحالة آخر تدوير.
- المفتاح المشترك للمجموعة: إنشاء، تدوير، تفعيل «أمان مزامنة المفاتيح» (رفض النبضات غير الموقّعة، وفترة سماح للمفتاح السابق).
- سجل عمليات المفاتيح.

## 4. المخططات التفاعلية

باستخدام recharts الموجود:
- مخطط دائري/شبكي لمواقع المجموعة حسب الحالة والمجموعة.
- مخطط أعمدة لمهام المحرّكات الدائمة (تشغيلات ناجحة/فاشلة لكل محرّك).
- مخطط خطي لعدد الصفوف المحلية مقابل المرآة عبر الزمن.
- مخطط نبضات المواقع/السيرفرات خلال 24 ساعة.

## 5. جداول قاعدة البيانات والعلاقات

جداول جديدة فقط (تظهر تلقائياً في مركز قواعد البيانات مثل بقية الجداول):

- `monitoring_entities`: صف لكل موقع/سيرفر مراقَب مع الكود والنوع والحالة المحسوبة — يربط `website_id` و`server_id` ويُغذّي الجدول الموحّد.
- `monitoring_links`: علاقات موقع↔سيرفر↔خدمة↔محرّك مع الدور (`hosts`, `serves`, `monitors`, `syncs`) والحالة.
- `monitoring_keys`: بصمة مفتاح كل كيان، النوع (موقع/سيرفر/مشترك)، الإصدار، آخر تدوير، حالة السماح.
- `monitoring_metrics_daily`: لقطة يومية (صفوف محلية/مرآة، نبضات، مواقع متصلة) لتغذية المخططات الزمنية.

لكل جدول: GRANT للأدوار، RLS بسياسات المالك/المدير، فهارس، ومحفّز `touch_updated_at`. لا مساس بـ`site_agents` أو `websites` أو `servers` أو `engine_schedules` القائمة.
