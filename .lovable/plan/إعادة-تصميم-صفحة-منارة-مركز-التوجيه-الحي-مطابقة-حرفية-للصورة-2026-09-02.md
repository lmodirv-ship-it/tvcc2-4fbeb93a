# إعادة تصميم صفحة منارة — مركز التوجيه الحي (مطابقة حرفية للصورة المرجعية المرسلة) — زر منارة أسفل زر المواقع

إعادة بناء تخطيط `/manara` ليطابق الصورة المرجعية: منارة مضيئة في المنتصف تحيط بها بطاقات زجاجية داكنة، مع الحفاظ على نفس البيانات والوظائف الحالية.

## التخطيط الجديد (بنفس شكل الصورة، 3 أعمدة)

```text
┌──────────────┬───────────────────────────┬──────────────┐
│ المسارات     │   منارة — مركز التوجيه    │ المواقع      │
│ الحية        │   الحي (بطاقة البطل)      │ والتطبيقات   │
│              │   [مشهد المنارة المتحرك]  │              │
├──────────────┤                           ├──────────────┤
│ تحديثات      │   شريط البحث/النشر        │ نقاط التوجيه │
│ العناوين     │   (معرّف + عنوان + نشر)   │ DNS/Nginx/…  │
├──────────────┴───────────────────────────┴──────────────┤
│            النشاط المباشر (خط زمني أفقي)                 │
└──────────────────────────────────────────────────────────┘
```

## البطاقات

- **بطاقة البطل (الوسط):** عنوان «منارة — مركز التوجيه الحي» مع كلمة «منارة» بلون ذهبي، سطر حالة «متصلة بـ TVCC» بنقطة نبض خضراء، وشارة «جميع المسارات متزامنة». تحتها مشهد `LighthouseScene` الحالي (سماء ليلية + نجوم + أشعة ذهبية) وحوله هالة كروية، ثم صندوق بحث/نشر موحّد: حقل واحد للبحث أو إدخال عنوان جديد + زر «نشر» دائري ذهبي متوهج.
- **المسارات الحية (يسار أعلى):** أول 3 مشاريع لها عنوان حالي؛ كل صف: الاسم، حالة «متصل»، المضيف والمنفذ المستخرَج من الـURL، وأيقونة خادم. رابط «عرض جميع المسارات» يفتح القائمة الكاملة.
- **تحديثات العناوين (يسار أسفل):** حلقة تقدّم (donut) بإجمالي التحديثات في المنتصف، وبجانبها مفاتيح ملوّنة: قيد النشر / مكتمل / معلق / فشل مع أعدادها من `updates`.
- **المواقع والتطبيقات (يمين أعلى):** نقاط النهاية من `endpoints` مصنّفة (موقع ويب / APK / PWA / خدمة) مع أيقونة مناسبة وحالة الاتصال.
- **نقاط التوجيه (يمين أسفل):** أربع بطاقات صغيرة DNS، Nginx، الخادم، الوكيل مع حالة كل منها.
- **النشاط المباشر (أسفل، عرض كامل):** خط زمني أفقي من `events` — دوائر أيقونات موصولة بخط منقّط متوهج، وتحت كل دائرة العنوان والوصف و«منذ N ثانية».

## الأسلوب البصري

- خلفية داكنة `bg-background` مع بطاقات نصف شفافة وحدود `border-primary/20` وتوهّج خفيف.
- ألوان من توكنات التصميم فقط (primary/success/warning/destructive)؛ اللمسة الذهبية للمنارة تُضاف كتوكن جديد `--manara-gold` في `src/styles.css` بدل ألوان مكتوبة يدوياً.
- الخطوط الواصلة بين البطاقات والمنارة: SVG منقّط مع أنيميشن `dash` متوهج (يظهر على الشاشات الكبيرة فقط).
- RTL محفوظ، واستجابة كاملة: عمود واحد على الهاتف، ثلاثة أعمدة من `lg`.

## بدون تغيير في المنطق

- نفس `listManara` ونفس `refetchInterval: 300000`.
- أزرار تحقق/نشر/تصحيح تبقى كما هي داخل بطاقاتها الجديدة.
- بطاقة شارة منارة (سكربت التضمين) تنتقل أسفل الصفحة كما هي.

## الملفات

- `src/routes/_authenticated/manara.tsx` — إعادة كتابة الواجهة فقط.
- `src/components/manara/` — مكوّنات فرعية جديدة: `RouteList`, `UpdatesDonut`, `EndpointsCard`, `RoutingPoints`, `ActivityTimeline`, `ConnectorLines`.
- `src/styles.css` — إضافة توكن الذهبي وأنيميشن الخطوط.

## إضافات مطلوبة (خارج صفحة منارة)

- **الشريط الجانبي:** عند الضغط على أي زر ينطوي تلقائياً (`setOpenMobile(false)` + طيّ على الشاشات الصغيرة/المتوسطة) لتظهر الصفحة المقصودة كاملة.
- **اتجاه الشريط حسب اللغة:** عربية → يمين (`side="right"`، `dir="rtl"`)، فرنسية/إنجليزية → يسار (`side="left"`، `dir="ltr"`) عبر ربطه بحالة اللغة في `src/i18n`.
- **تكبير شعار TVCC** في رأس الشريط الجانبي.
- عرض قائمة المواقع داخل صفحة منارة غير ضروري؛ يُكتفى ببطاقة «المواقع والتطبيقات» المختصرة كما في الصورة.
